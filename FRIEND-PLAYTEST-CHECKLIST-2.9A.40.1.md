# Friend Playtest Checklist — 2.9A.40.1

The point of this test is not “can you find every feature?” It is whether the new systems make the game easier to understand and more tempting to keep playing.

## 1. Build switching
- Start Story normally and open the Story menu during exploration.
- Find **RRVVFO BUILD** without being told where it is.
- Switch Balanced → Fire Pressure → Improviser.
- Create a **Custom** loadout with four techniques and two passives.
- Close the menu, fight, then return and change the build again.
- During an active fight/QTE, confirm the game explains why the build is locked.

Ask: **Did changing builds feel like part of the adventure, or like menu homework?**

## 2. Enemy readability
- Fight at least one Heavy, Trickster, Guard, Ranged, and Support archetype.
- Before explaining the archetype system, ask what the player thinks each enemy is trying to do.
- Check whether role icon + body shape + behavior communicate the answer quickly.

Ask: **Could you tell who needed a different approach without reading patch notes?**

## 3. Support enemy
- Let a Support begin casting once.
- Interrupt the next cast by attacking it.
- Confirm the heal does not land after interruption.

Ask: **Did “stop the Support” feel like a decision you made, rather than hidden game logic?**

## 4. Chapter 4 squad targeting
Test all available inputs:
- Keyboard target cycling.
- Controller Interact target cycling.
- Touch **TARGET** control if available.

Ask: **Could you deliberately finish a weak enemy or switch to the Support instead of fighting the target the game chose?**

## 5. Flow Cancel
- Play the Chapter 1 optional road fight without explaining Flow Cancel first.
- See whether the in-game opening prompt makes the player try Dash after a connected hit.

Ask: **After learning it once, did you voluntarily use it again?**

## 6. Chapter gimmick cards
At the start of each chapter, check whether the player understands the expected gameplay flavor:
- Ch1 movement/adventure.
- Ch2 combat/tournament.
- Ch3 investigation.
- Ch4 party journey → solo survival.

Ask: **Did each chapter feel mechanically different, not just look/story different?**

## Success condition
The strongest positive signal is not “everything worked.” It is the player voluntarily doing one of these without being asked:
- changes their build to try another approach,
- targets a specific enemy because of its role,
- retries a fight for a better result,
- uses Flow Cancel because it feels good,
- explores an optional route/mission,
- asks to keep playing.
