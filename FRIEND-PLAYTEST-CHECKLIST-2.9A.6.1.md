# Friend Playtest Checklist — Prototype 2.9A.7

## Mouse controls first

Test all four places with the same controls:

1. VS CPU
2. Training
3. Arena
4. Story Chapters 1–3

Confirm:

- Left click attacks.
- J performs the same Light action.
- Right click holds Block.
- L performs the same Block action.
- Right click releases Block immediately when released.
- Pausing while holding right click does not leave the fighter stuck blocking.
- The tutorial changes to M1/M2 prompts after mouse input.

## Full Chapter control check

Use WASD, Space, M1/J, K, I, M2/L, Shift, U, C, O, E, Z, and 1–5. Report any mode where one of those changes meaning.

## Settings check

In Arena controls, switch Left Mouse Click between Light and Heavy. Then return to VS or Training and confirm the same primary-click choice is respected there.
