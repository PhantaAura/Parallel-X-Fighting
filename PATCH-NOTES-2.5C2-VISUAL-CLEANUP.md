# Prototype 2.5C2 — Mission 0 Visual Cleanup

Fixes the visual problems seen in the first playable Mission 0 build.

## Fixed

- Rebuilt the Sage atlas from complete isolated character poses instead of grid slices.
- Sage stance, running, light attacks, hurt pose, and prediction dodge now animate between whole frames.
- Removed the opaque white sheet background trapped between the Sage's legs.
- Removed the same opaque white background wedges from Rrvvfo's arena sprites.
- Replaced dialogue portrait atlas offsets with dedicated single-character portraits.
- Tightened and restyled the dialogue box to more closely match the compact Sonic Battle presentation.
- Preserved Mission 0 logic, Sage auto-dodging, Shots of Agony progression, story saves, and 2.5B movement.

The Sage remains story-only and is not added to the playable roster.
