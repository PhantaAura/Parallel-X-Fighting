# Parallels X Prototype 2.6.2

This is the committed release name for the Parallels Battle Menu Flow patch.

Included:
- Horizontal Choose Your Mode menu
- Story Character / Episode Select
- Mission Select and briefing flow
- Matching VS, stage, settings, and extras presentation
- Rrvvfo Mission 1 and Mission 2 support
- Scoped menu styling so combat HUD styling is not changed
- Readability, mobile layout, and keyboard-focus improvements

The animated intro remains planned for a later update.
