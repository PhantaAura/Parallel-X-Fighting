# Parallels X Prototype 2.7A

Install this patch over the current `main` branch of `PhantaAura/Parallel-X-Fighting`.

It starts the larger overhaul by converting Rrvvfo's short missions into a continuous chapter route and adding the persistent Combat Manual framework. The later living-hub, roaming encounter, Run QTE, side-story, and Training Level systems now have a stable route structure to plug into without rebuilding Story Mode again.
